二、第一步：安装 JDK 17（Java 开发工具包）
================================================================================

  ★ 什么是 JDK？
  JDK 是 Java 开发工具包，后端代码是用 Java 编写的，需要 JDK 来编译和运行。

  ◆ Windows 安装方法：

  1. 打开浏览器，访问 Oracle 官方下载页面：
     https://www.oracle.com/java/technologies/downloads/#java17

     或使用免费的 Eclipse Temurin（推荐）：
     https://adoptium.net/temurin/releases/?version=17

  2. 选择 "Windows x64" 版本，下载 .msi 安装包（例如：
     OpenJDK17U-jdk_x64_windows_hotspot_17.0.x.msi）

  3. 双击下载的 .msi 文件，按照安装向导操作：
     - 点击 "Next"
     - 勾选 "Set JAVA_HOME variable"（非常重要！）
     - 勾选 "Add to PATH"（非常重要！）
     - 点击 "Install"
     - 等待安装完成，点击 "Finish"

  4. 验证安装是否成功：
     a) 按 Win + R，输入 cmd，按回车，打开命令提示符
     b) 输入以下命令并按回车：

        java -version

     c) 如果看到类似以下输出，说明安装成功：

        openjdk version "17.0.x" 2024-xx-xx
        OpenJDK Runtime Environment ...
        OpenJDK 64-Bit Server VM ...

     ※ 如果提示 "java 不是内部或外部命令"，请参考"常见问题"章节。

  ◆ macOS 安装方法：

  1. 打开终端（Terminal），输入：

     brew install openjdk@17

  2. 按提示设置环境变量后，验证：

     java -version

  ◆ Linux (Ubuntu) 安装方法：

  1. 打开终端，输入：

     sudo apt update
     sudo apt install openjdk-17-jdk

  2. 验证：

     java -version

================================================================================
三、第二步：安装 Apache Maven（Java 构建工具）
================================================================================

  ★ 什么是 Maven？
  Maven 是 Java 项目的构建工具，用来自动下载项目需要的依赖库并编译代码。

  ◆ Windows 安装方法：

  1. 打开浏览器，访问 Maven 官方下载页面：
     https://maven.apache.org/download.cgi

  2. 找到 "Binary zip archive" 一行，点击下载链接，例如：
     apache-maven-3.9.6-bin.zip

  3. 下载完成后，将 zip 文件解压到一个简单的路径，例如：
     C:\apache-maven-3.9.6

     ※ 路径中不要包含中文或空格！

  4. 配置环境变量：
     a) 右键"此电脑" → "属性" → "高级系统设置" → "环境变量"
     b) 在"系统变量"中找到 "Path"，双击打开
     c) 点击"新建"，输入 Maven 的 bin 目录路径：
        C:\apache-maven-3.9.6\bin
     d) 一路点击"确定"保存

  5. 验证安装（需要重新打开一个新的命令提示符窗口）：

     mvn -version

     如果看到类似以下输出，说明安装成功：

     Apache Maven 3.9.6
     Maven home: C:\apache-maven-3.9.6
     Java version: 17.0.x

  ◆ macOS 安装方法：

     brew install maven

  ◆ Linux (Ubuntu) 安装方法：

     sudo apt install maven

================================================================================
四、第三步：安装 Node.js（前端运行环境）
================================================================================

  ★ 什么是 Node.js？
  Node.js 是一个 JavaScript 运行环境，前端项目需要它来安装依赖和启动开发服务器。
  安装 Node.js 会同时安装 npm（包管理器）。

  ◆ Windows 安装方法：

  1. 打开浏览器，访问 Node.js 官方网站：
     https://nodejs.org/

  2. 下载 LTS（长期支持）版本（建议 18.x 或 20.x），例如：
     node-v20.11.0-x64.msi

  3. 双击下载的 .msi 文件，按照安装向导操作：
     - 一路点击 "Next"
     - 确保勾选了 "Add to PATH"
     - 点击 "Install"
     - 等待安装完成，点击 "Finish"

  4. 验证安装（重新打开命令提示符）：

     node -v          （应显示 v18.x.x 或更高）
     npm -v           （应显示 9.x.x 或更高）

  ◆ macOS 安装方法：

     brew install node@20

  ◆ Linux (Ubuntu) 安装方法：

     curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
     sudo apt-get install -y nodejs

五、第四步：安装 MySQL 8.0（数据库）
================================================================================

  ★ 什么是 MySQL？
  MySQL 是一个关系型数据库管理系统，本项目的所有数据（用户、文档、评论等）
  都存储在 MySQL 数据库中。

  ◆ Windows 安装方法：

  1. 打开浏览器，访问 MySQL 官方下载页面：
     https://dev.mysql.com/downloads/installer/

  2. 下载 "MySQL Installer for Windows"（建议选择完整版 mysql-installer-community）

  3. 双击安装包，按向导操作：
     a) 选择 "Custom" 安装类型
     b) 在左侧展开 "MySQL Servers" → "MySQL Server 8.0" → 选择最新版本
        点击绿色箭头将其添加到右侧
     c) 点击 "Next" → "Execute"（等待下载和安装）
     d) 进入配置页面：
        - Type and Networking: 保持默认（端口 3306）
        - Authentication Method: 选择 "Use Legacy Authentication Method"
          （推荐，兼容性更好）
        - Root Password: 设置 root 用户密码
          ┌─────────────────────────────────────────────────────────┐
          │  【重要】建议将密码设置为: root                         │
          │  如果设置了其他密码，需要在后面修改后端配置文件          │
          └─────────────────────────────────────────────────────────┘
        - Windows Service: 保持默认，勾选 "Start the MySQL Server 
          at System Startup"
     e) 点击 "Execute" 完成配置
     f) 点击 "Finish"

  4. 将 MySQL 添加到系统 PATH（如果安装时没有自动添加）：
     a) 找到 MySQL 安装目录，通常是：
        C:\Program Files\MySQL\MySQL Server 8.0\bin
     b) 将该路径添加到系统环境变量 Path 中（方法同 Maven）

  5. 验证安装（重新打开命令提示符）：

     mysql -u root -p

     输入密码后，如果看到 "mysql>" 提示符，说明安装成功。
     输入 exit 退出。

  ◆ macOS 安装方法：

     brew install mysql
     brew services start mysql
     mysql_secure_installation    （设置 root 密码为 root）

  ◆ Linux (Ubuntu) 安装方法：

     sudo apt update
     sudo apt install mysql-server
     sudo mysql_secure_installation

六、第五步：初始化数据库
================================================================================

  这一步将创建项目需要的数据库和数据表。

  1. 打开命令提示符（Windows）或终端（macOS/Linux）

  2. 进入 MySQL 命令行：

     mysql -u root -p

     输入您的 MySQL root 密码（如果按建议设置的就是：root）

  3. 此时您应该看到 "mysql>" 提示符，依次执行以下命令：

     ┌─────────────────────────────────────────────────────────────┐
     │  方式一：直接在 MySQL 命令行中执行（推荐）                   │
     └─────────────────────────────────────────────────────────────┘

     在 mysql> 提示符下输入：

     source 你的项目路径/backend/sql/init.sql;

     例如（Windows，注意使用正斜杠 / ）：

     source C:/Users/你的用户名/Desktop/协作编辑系统/backend/sql/init.sql;

     或者（如果路径含中文，可以用下面的方式）：

     先手动创建数据库，然后导入：

     CREATE DATABASE IF NOT EXISTS collab_edit
       DEFAULT CHARACTER SET utf8mb4
       COLLATE utf8mb4_unicode_ci;
     USE collab_edit;

     然后将 init.sql 文件的内容复制粘贴到 mysql> 中执行。

     ┌─────────────────────────────────────────────────────────────┐
     │  方式二：使用命令行直接导入（Windows CMD，注意不是 PowerShell）│
     └─────────────────────────────────────────────────────────────┘

     退出 mysql（输入 exit），然后在 CMD 中执行：

     mysql -u root -proot --default-character-set=utf8mb4 < "项目路径\backend\sql\init.sql"

     注意：-p 和密码之间没有空格！

     ┌─────────────────────────────────────────────────────────────┐
     │  方式三：使用图形化工具（最简单，推荐小白使用）               │
     └─────────────────────────────────────────────────────────────┘

     a) 下载安装 Navicat（https://navicat.com/）
        或 DBeaver（https://dbeaver.io/ 免费）
        或 MySQL Workbench（MySQL 官方自带）

     b) 创建连接：
        - 主机: localhost
        - 端口: 3306
        - 用户名: root
        - 密码: root（或您设置的密码）

     c) 连接成功后，新建查询窗口

     d) 将 backend/sql/init.sql 文件的全部内容复制粘贴到查询窗口中

     e) 点击"运行"或"执行"按钮

  4. 验证数据库是否创建成功：

     mysql -u root -p
     （输入密码）

     SHOW DATABASES;

     应该能看到 collab_edit 数据库。然后：

     USE collab_edit;
     SHOW TABLES;

     应该看到以下 8 张表：
     ┌────────────────────────┐
     │ Tables_in_collab_edit  │
     ├────────────────────────┤
     │ audit_log              │
     │ document               │
     │ document_comment       │
     │ document_member        │
     │ document_version       │
     │ operation_log          │
     │ sys_user               │
     │ system_config          │
     └────────────────────────┘

     输入 exit 退出 MySQL。

七、第六步：配置后端数据库连接（如果你的 MySQL 密码不是 root）
================================================================================

  如果您的 MySQL root 密码不是 "root"，需要修改后端配置文件。

  1. 用任意文本编辑器打开以下文件：
     项目目录/backend/src/main/resources/application.yml

  2. 找到以下内容：

     spring:
       datasource:
         url: jdbc:mysql://localhost:3306/collab_edit?useUnicode=true&characterEncoding=utf-8&useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true
         username: root
         password: root

  3. 将 password 的值修改为您的实际 MySQL 密码，例如：

         password: 你的实际密码

  4. 如果 MySQL 端口不是默认的 3306，也需要修改 url 中的端口号。

  5. 保存文件。

八、第七步：启动后端服务
================================================================================

  1. 打开命令提示符（Windows）或终端（macOS/Linux）

  2. 进入项目的 backend 目录：

     cd 项目路径/backend

     例如（Windows）：

     cd C:\Users\你的用户名\Desktop\协作编辑系统\backend

     例如（macOS/Linux）：

     cd ~/Desktop/协作编辑系统/backend

  3. 执行以下命令启动后端：

     mvn spring-boot:run

     ┌─────────────────────────────────────────────────────────────┐
     │  【首次运行说明】                                           │
     │  首次运行时，Maven 会自动从网络下载所有依赖库，             │
     │  这个过程可能需要 5~15 分钟，取决于您的网络速度。           │
     │  请耐心等待，不要关闭窗口！                                 │
     │                                                             │
     │  如果下载很慢，可以配置 Maven 国内镜像（见常见问题章节）    │
     └─────────────────────────────────────────────────────────────┘

  4. 等待启动完成，当您看到以下输出时，说明后端启动成功：

     Started CollabApplication in x.xxx seconds (JVM running for x.xxx)

     同时会看到：

     Tomcat started on port(s): 8080 (http)

     ┌─────────────────────────────────────────────────────────────┐
     │  【重要】后端启动后，不要关闭这个命令行窗口！               │
     │  关闭窗口 = 关闭后端服务                                    │
     │  需要另开一个新窗口来启动前端。                              │
     └─────────────────────────────────────────────────────────────┘

  5. 如果启动失败，请参考"常见问题"章节。

九、第八步：安装前端依赖并启动
================================================================================

  ※ 确保后端已经成功启动并且命令行窗口没有关闭！

  1. 打开一个 新的 命令提示符窗口（不要关闭后端的窗口）

  2. 进入项目的 frontend 目录：

     cd 项目路径/frontend

     例如（Windows）：

     cd C:\Users\你的用户名\Desktop\协作编辑系统\frontend

  3. 安装前端依赖包：

     npm install

     ┌─────────────────────────────────────────────────────────────┐
     │  【首次运行说明】                                           │
     │  首次运行时，npm 会从网络下载所有前端依赖库，               │
     │  这个过程可能需要 2~5 分钟。                                │
     │                                                             │
     │  如果下载很慢，可以先配置 npm 国内镜像：                    │
     │  npm config set registry https://registry.npmmirror.com     │
     │  然后再执行 npm install                                     │
     └─────────────────────────────────────────────────────────────┘

     等待安装完成，看到类似以下输出即可：

     added xxx packages in xx.xxs

  4. 启动前端开发服务器：

     npm run dev

  5. 等待启动完成，当您看到以下输出时，说明前端启动成功：

     VITE v5.4.21  ready in xxx ms

       ➜  Local:   http://localhost:5173/
       ➜  Network: use --host to expose

     ┌─────────────────────────────────────────────────────────────┐
     │  前端也不要关闭这个窗口！                                   │
     │  此时应该有两个命令行窗口同时运行：                         │
     │    窗口1 → 后端服务（端口 8080）                            │
     │    窗口2 → 前端服务（端口 5173）                            │
     └─────────────────────────────────────────────────────────────┘

================================================================================
十一、常见问题与解决方案
================================================================================

  ────────────────────────────────────────────
  Q1: java -version 提示 "不是内部或外部命令"
  ────────────────────────────────────────────
  原因：JDK 没有正确添加到系统 PATH 环境变量。
  解决：
  1. 找到 JDK 安装目录（例如 C:\Program Files\Java\jdk-17\bin）
  2. 右键"此电脑" → "属性" → "高级系统设置" → "环境变量"
  3. 在"系统变量"中找到 Path，双击编辑
  4. 新建一条，填入 JDK 的 bin 目录路径
  5. 确定保存，然后重新打开命令提示符

  ────────────────────────────────────────────
  Q2: mvn 命令提示 "不是内部或外部命令"
  ────────────────────────────────────────────
  原因：Maven 没有添加到系统 PATH。
  解决：参考第三步的环境变量配置。

  ────────────────────────────────────────────
  Q3: Maven 下载依赖非常慢
  ────────────────────────────────────────────
  原因：默认从国外仓库下载。
  解决：配置阿里云镜像。
  1. 找到 Maven 配置文件：
     Windows: C:\Users\你的用户名\.m2\settings.xml
     （如果没有这个文件，就新建一个）
  2. 写入以下内容：

     <?xml version="1.0" encoding="UTF-8"?>
     <settings>
       <mirrors>
         <mirror>
           <id>aliyunmaven</id>
           <mirrorOf>*</mirrorOf>
           <name>阿里云公共仓库</name>
           <url>https://maven.aliyun.com/repository/public</url>
         </mirror>
       </mirrors>
     </settings>

  3. 保存后重新执行 mvn spring-boot:run

  ────────────────────────────────────────────
  Q4: 后端启动报 "Port 8080 already in use"
  ────────────────────────────────────────────
  原因：端口 8080 已被其他程序占用。
  解决（Windows）：
  1. 打开 CMD，执行：netstat -ano | findstr :8080
  2. 记下最后一列的 PID 数字
  3. 执行：taskkill /F /PID 那个PID数字
  4. 重新启动后端

  解决（macOS/Linux）：
  1. 执行：lsof -i :8080
  2. 记下 PID
  3. 执行：kill -9 那个PID

  ────────────────────────────────────────────
  Q5: 后端启动报 "Communications link failure" 或数据库连接失败
  ────────────────────────────────────────────
  原因：MySQL 没有启动，或者密码不对。
  解决：
  1. 确认 MySQL 服务正在运行：
     Windows: 在"服务"中找到 MySQL80，确认状态为"正在运行"
     macOS: brew services list | grep mysql
     Linux: sudo systemctl status mysql
  2. 确认密码正确：尝试用 mysql -u root -p 登录
  3. 确认数据库 collab_edit 已创建：在 MySQL 中执行 SHOW DATABASES;
  4. 检查 application.yml 中的数据库配置是否正确

  ────────────────────────────────────────────
  Q6: npm install 报错或很慢
  ────────────────────────────────────────────
  解决：
  1. 配置淘宝/npmmirror 镜像：
     npm config set registry https://registry.npmmirror.com
  2. 清除缓存后重试：
     npm cache clean --force
     npm install
  3. 如果仍然失败，删除 node_modules 文件夹和 package-lock.json，
     然后重新执行 npm install

  ────────────────────────────────────────────
  Q7: 前端页面打开后显示空白或报错
  ────────────────────────────────────────────
  解决：
  1. 确认后端服务正在运行（端口 8080）
  2. 按 F12 打开浏览器开发者工具，查看 Console 是否有错误
  3. 尝试按 Ctrl + Shift + R 强制刷新页面（清除缓存）
  4. 确认 Vite 开发服务器正在运行（端口 5173）

  ────────────────────────────────────────────
  Q8: 登录后提示 "用户名或密码错误"
  ────────────────────────────────────────────
  解决：
  1. 确认使用的是默认账号：用户名 admin，密码 admin123
  2. 确认数据库初始化成功（init.sql 已执行）
  3. 如果之前修改过密码，可以重新执行 init.sql 重置

  ────────────────────────────────────────────
  Q9: 如何停止服务？
  ────────────────────────────────────────────
  1. 停止前端：在前端命令行窗口按 Ctrl + C
  2. 停止后端：在后端命令行窗口按 Ctrl + C
  3. 停止数据库（通常不需要）：
     Windows: 在"服务"中停止 MySQL80
     macOS: brew services stop mysql
     Linux: sudo systemctl stop mysql

  ────────────────────────────────────────────
  Q10: 如何重置所有数据？
  ────────────────────────────────────────────
  1. 停止后端服务
  2. 登录 MySQL：mysql -u root -p
  3. 执行：DROP DATABASE collab_edit;
  4. 重新执行 init.sql（参考第六步）
  5. 重新启动后端

================================================================================
十二、生产环境部署（可选）
================================================================================

  如果需要将系统部署到服务器供多人使用，按以下步骤操作：

  ◆ 1. 构建前端静态文件

     cd frontend
     npm run build

     构建完成后会生成 dist 目录，包含所有静态资源。

  ◆ 2. 打包后端 JAR

     cd backend
     mvn clean package -DskipTests

     打包完成后在 backend/target/ 目录下生成 collab-edit-1.0.0.jar

  ◆ 3. 部署到服务器

     a) 在服务器上安装 JDK 17、MySQL 8.0
     b) 初始化数据库（同第六步）
     c) 上传 JAR 文件到服务器
     d) 配置 Nginx 反向代理（同时代理前端静态文件和后端 API）：

        server {
            listen 80;
            server_name your-domain.com;

            location / {
                root /path/to/frontend/dist;
                try_files $uri $uri/ /index.html;
            }

            location /api/ {
                proxy_pass http://localhost:8080;
                proxy_set_header Host $host;
                proxy_set_header X-Real-IP $remote_addr;
            }

            location /ws/ {
                proxy_pass http://localhost:8080;
                proxy_http_version 1.1;
                proxy_set_header Upgrade $http_upgrade;
                proxy_set_header Connection "upgrade";
            }
        }

     e) 启动后端：

        nohup java -jar collab-edit-1.0.0.jar --spring.datasource.password=你的数据库密码 &

     f) 启动 Nginx：

        sudo nginx -s reload
