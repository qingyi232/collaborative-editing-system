===================================================
  协作编辑系统 Bug 修复补丁 - 部署说明
  修复日期: 2026-05-14
===================================================

本补丁修复了以下两个问题：
1. 资源监控页面自动刷新间隔不随系统配置变化
2. 文档"公开访问"开关没有效果

===================================================
  补丁包含的文件（共2个）
===================================================

文件1: frontend\src\views\admin\Monitor.vue
文件2: backend\src\main\resources\mapper\DocumentMapper.xml

===================================================
  部署步骤
===================================================

【步骤一】覆盖前端文件

将补丁中的文件:
  bugfix-patch\frontend\src\views\admin\Monitor.vue

覆盖到项目中的:
  协作编辑系统\frontend\src\views\admin\Monitor.vue

【步骤二】覆盖后端文件

将补丁中的文件:
  bugfix-patch\backend\src\main\resources\mapper\DocumentMapper.xml

覆盖到项目中的:
  协作编辑系统\backend\src\main\resources\mapper\DocumentMapper.xml

【步骤三】重新构建前端

打开命令行，进入前端目录，执行：
  cd 协作编辑系统\frontend
  npm run build

构建完成后，将 dist 目录的内容部署到 Web 服务器。

【步骤四】重新编译后端

打开命令行，进入后端目录，执行：
  cd 协作编辑系统\backend
  mvn clean package -DskipTests

编译完成后，用新生成的 jar 包替换服务器上的旧包并重启：
  java -jar target/协作编辑系统.jar

【步骤五】验证修复

验证问题1：
  1. 用管理员账号登录
  2. 进入"系统配置"页面
  3. 将 websocket_heartbeat_interval 修改为 5
  4. 进入"资源监控"页面
  5. 确认右上角显示"每 5 秒自动刷新"

验证问题2：
  1. 用账号A登录，创建一个文档
  2. 在编辑器右侧"设置"面板中，开启"公开访问"
  3. 用另一个账号B登录
  4. 在"与我共享"或"我的文档"列表中，确认能看到账号A的公开文档
  5. 点击该文档确认可以正常打开

===================================================
  注意事项
===================================================

- 覆盖前建议备份原文件
- 前端构建需要 Node.js 环境
- 后端编译需要 Maven 和 JDK 环境
- 本补丁不涉及数据库修改，无需执行 SQL
